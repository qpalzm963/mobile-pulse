# MOBILE PULSE 文章品質標準

MOBILE PULSE 專注於提供高訊號、為真正交付產品的工程師整理的技術洞察。文章架構應依主題本質自由組織，不強制套用死板的固定模板。

## 發布核心品質標準

1. **結論明確**：開場或前言讓讀者迅速掌握核心價值、為何重要與主要結論。
2. **真實查證與精準度**：所有技術主張、版本資訊與程式碼範例必須基於真實官方文件或開源實作，禁止虛構假 API。
3. **深入淺出與結構清晰**：適當運用標題分段、程式碼區塊、清單或對比，每段專注於一個重點，拒絕空泛長文。
4. **具備實務價值**：內容應能為讀者帶來具體的工程思考、架構權衡或落地參考。
5. **附原始來源**：文末或相關段落附上官方專案、規格 RFC 或原始出處連結。

---

## 站點整合規範

- 文章頁面置於 `app/articles/<slug>/page.tsx`，使用 `<article className="article-body">` 容器。
- 文章結尾須包含 `<Feedback slug="<slug>" />`（收集匿名讀者反饋）。
- 必須在 `data/articles.ts` 的 `ARTICLES` 陣列註冊該文章 metadata（`slug`、`title`、`summary`、`publishedAt`、`tags`、`href`）。
- 新增模組樣式時**務必加上 `.article-body` 前綴**（避免全域 CSS 覆蓋）。

---

## 禁止項目

- ❌ 示意用的虛構/假 API 程式碼。
- ❌ 為湊版面生成的無意義裝飾圖或抽象 icon。
- ❌ 無結構的長篇流水帳堆疊。
- ❌ 收到寫文章指令時僅在對話框輸出 Markdown 草稿（應直接產出 Next.js 頁面並註冊）。
