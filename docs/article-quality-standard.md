# MOBILE PULSE 文章品質標準

每次產文先選擇 HTML 敘事模組，再撰寫文案；不使用 Mermaid 或通用自動流程圖。

## 發布最低門檻

1. 有編輯概念的主視覺區：標題、短摘要、至少一組數字／標籤。
2. 至少兩個資訊模組：比較矩陣、事件卡、時間線、互動步驟、決策卡或 Before/After 之一。
3. 每段只傳達一個觀點；大多數段落不超過四行。
4. 至少一個讀者能帶走的行動區塊。
5. 所有事實附原始來源；視覺模組必須協助理解，不能只是裝飾。

## 版型選擇

| 類型 | 必備 HTML 模組 |
| --- | --- |
| AI 大小事 | 焦點封面、事件卡、影響力矩陣、快讀清單 |
| GitHub 雙週雷達 | 熱度卡、用途比較、適用情境、上手指令 |
| Flutter 實戰拆解 | 風險地圖、可切換步驟、決策卡、驗收清單 |

## 禁止項目

- Mermaid 流程圖。
- 為填版面生成的抽象圖或無意義 icon。
- 只有標題、長段落與來源清單的文章。
