# 每篇發布前檢查

## 內容

- [ ] 文章有一個讀者會在首屏理解的明確結論。
- [ ] 有一個可採取的行動、選擇建議或實作清單。
- [ ] 每一項可查證的主張均有原始來源。
- [ ] 文字段落經編輯，沒有連續長段落堆疊。

## HTML 閱讀體驗

- [ ] 首屏具備標題、摘要、日期／閱讀時間與至少一個訊號數字或標籤。
- [ ] 使用至少兩種與內容有關的 HTML 資訊模組。
- [ ] 資訊模組在手機寬度仍可閱讀與操作。
- [ ] 圖像、色彩與資料視覺化皆服務於理解；沒有 Mermaid。
- [ ] 所有互動元素都可用鍵盤操作，並具備文字標籤。

## 發布判定

只要其中一項未通過，文章維持預覽，不加入首頁文章清單。
