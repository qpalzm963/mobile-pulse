# 每篇發布前檢查

## 內容品質

- [ ] **開場與核心結論**：讀者能快速掌握文章主題與核心價值。
- [ ] **技術真實性**：程式碼範例與技術主張皆經查證，均為真實 API 與語法。
- [ ] **排版節奏**：結構層級清晰，適度分段，無連續過長的大段落。
- [ ] **原始來源**：附有官方專案或規格文件之超連結（`ul.sources`）。

## 站點整合與功能

- [ ] **回饋元件**：文末包含 `<Feedback slug="..." />`。
- [ ] **首頁註冊**：已在 `data/articles.ts` 的 `ARTICLES` 陣列註冊該文章 metadata。
- [ ] **自動化驗證**：通過 `npm test` 與 `npm run build`。

## 發布判定

只要其中一項未通過，文章不得發布或加入首頁清單。
