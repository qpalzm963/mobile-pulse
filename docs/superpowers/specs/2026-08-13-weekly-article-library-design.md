# App 開發週報文章網站：設計規格

## 目的

建立可公開瀏覽的繁體中文 App 開發週報文章站。站長透過 Codex 新增文章；讀者無須登入即可依標籤瀏覽、閱讀來源與留下「有用／沒用」回饋。

## 功能範圍

- 首頁：焦點週報、文章卡片、五個分類標籤篩選、無結果狀態。
- 文章頁：封面、摘要、圖文內容、來源、相關文章與返回首頁。
- 回饋：每篇文章可按「有用」或「沒用」。選擇保存在該瀏覽器的 `localStorage`，重整後仍會顯示；可改選或取消，不需要帳號與後端。
- 內容：每篇文章由獨立 HTML 頁與 `data/articles.js` 的 metadata 管理，方便 Codex 新增。

## 視覺與技術

- 深海軍藍／近黑底色，電光青綠重點色，科技編輯週刊風格。
- 純 HTML、CSS、原生 JavaScript；不引入建置工具、資料庫或外部 API。
- 響應式：桌面三欄、平板兩欄、手機單欄；圖片和 SVG 不可溢位。

## 驗收

- 首頁可閱讀焦點週報，五個標籤能篩選並回到全部。
- 首篇週報有獨立網址、內文圖表與來源清單。
- 有用／沒用按鈕會更新可見數字與選取狀態，且同篇只能維持一種回饋。
- 回饋重整後仍存在；缺少瀏覽器儲存權限時，按鈕仍能在當次頁面運作。
